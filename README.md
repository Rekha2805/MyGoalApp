# 🌸 MyGoalApp – Personal Goal Tracker

A simple and user-friendly mobile application built with **React Native and Expo** to help users manage their personal goals. MyGoalApp features a soft pink and cream design, Light and Dark Mode, and local storage to keep goals saved between app sessions.

## ✨ Features

- **Add Goals:** Create personal goals using a simple input form.
- **Delete Goals:** Remove goals when they are no longer needed.
- **Light & Dark Mode:** Switch between themes for a comfortable viewing experience.
- **Persistent Storage:** Goals and theme preferences are saved locally using AsyncStorage.
- **Responsive UI:** Clean, mobile-friendly layout with a pink and cream color palette.
- **User-Friendly Design:** Simple navigation and clear controls.

## 🛠️ Technologies Used

- React Native
- Expo
- JavaScript
- AsyncStorage
- Expo Linear Gradient
- React Native Safe Area Context

## 📱 Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- [Expo Go](https://expo.dev/go) on your mobile device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rekha2805/MyGoalApp.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MyGoalApp
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Scan the QR code using Expo Go to open the app on your device.

## 💾 Data Storage

MyGoalApp uses AsyncStorage to save goals and theme preferences locally on the device. This means saved data persists across app restarts on the same installation.

## 🎨 Design

The app uses a soft pink (`#FF95A5`) and cream (`#FFF6DC`) color palette in Light Mode, with darker backgrounds in Dark Mode.
